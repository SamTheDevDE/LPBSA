# Contributing

Contributions should remain focused on LuckPerms-based Velocity backend access control. Before opening a pull request:

```text
./gradlew test
./gradlew build
```

Add or update tests for behavior changes, keep configuration reloads atomic, and avoid caching authorization decisions. Update user-facing documentation when commands, permissions, or configuration change.

Pull requests should briefly explain what changed, why it is needed, how it was tested, and whether documentation was updated. No particular editor or IDE is required.
